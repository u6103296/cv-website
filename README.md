## Project Analysis

### User Persona

My ideal user persona is a recruiter or a manager from a technology company who is looking to hire junior software developers or engineering students.

This user wants to quickly check the candidate's education, experience, technical skills and projects. 

They value clear, concise and well-organized information, because they may need to review several profiles.

They also want to be able to identify the most relevant information quickly and easily access the projects that the candidate has worked on, in order to understand the candidate's skills and abilities.

### Information Architecture

The website is organized as a single-page CV, where all the main information is displayed vertically in a clear order, to try to make the content easy to review for potential recruiters or managers who may be interested in hiring me.

I decided to create a linear structure, so that the user can find all the information by simply scrolling through the page, without the need for a navigation menu.

The first section is the header, which contains my main information, such as: a photo of myself, my full name, the studies I am currently doing, my main contact information and a brief introduction about myself. This allows the user to immediately know who I am and how they can contact me.

After that, the page continues with the "About me" section, followed by "Experience" and "Education". These sections are placed near the top because they are really important: 

* The "About me" section introduces me as a Computer Engineering student and explains what my main interests are.
* The "Experience" section allows the manager to see that I have a working background, so that they realize that even though I am a "junior", I have already taken part in some software and engineering projects.
* The "Education" section allows the manager to clearly see where my studies and knowledge come from.


The "Skills" and "Languages" sections are placed next. They use visual percentage indicators, which allow the user to quickly compare my level in different technologies and languages without reading any description.

Finally, there is a section called "Projects" that includes a brief description of a project I made and also has a link to access it. This way, the recruiter can see an example of the type of work I am prepared to do.

### Visual Design

My objective was to create a clean and professional CV, so that it would be easy to read and visually simple. 

However, I had never designed a CV for a technological job before, only for some summer part-time jobs. That's why before starting the design I decided to look on Canva for different CV examples to get some references about how the colors, spacing and organization could be.
Note: I used these examples just as inspiration. I created my own design, step-by-step, in Figma.

I decided to use different shades of blue as the main colors of the website, because I found on [Color-Hex](https://www.color-hex.com/) that blue is a color commonly associated with technology.

However, the background of almost the entire page (except for the header and the "Projects" section) is white, in order to create contrast with the blue elements and make the text easier to read.

I decided to use only one simple font, with different sizes and weights, in order to clearly distinguish between titles, subtitles and normal text.

For the "Skills" and "Languages" sections, I used circular percentage indicators instead of only text, because I think they are really visual and make the information easier to understand.

Finally, the "Projects" section has a project description, an image and a link, in order to make this section stand out.
